**M7 — Package Pricing Engine Foundation (APPROVED 2026-08-18; commit `d88ded8` on `feat/payload-backend` — NOT merged to main, NOT deployed to production):** An application-layer pricing foundation, not commercial pricing activation. The platform carried five money representations — a bare rupee `number`, Payload's `{amount,currency}` group, a hardcoded `"INR"` literal, M4's optional-currency rate lines, and a formatted STRING on the departures board — all floats, none agreeing whether a currency is even required. Survivable for `unitPrice × quantity`; not survivable once a percentage markup or a tax rate applies. `pricing/money.ts` makes the canonical type an INTEGER of minor units carrying its own currency: no implicit INR, percentages as whole basis points (1% = 100) so a rate is never itself a float, one rounding policy (**half-up away from zero**, applied once per boundary so error cannot compound), and `allocate()` distributes remainders so the parts always sum back to the whole. Currency mismatch, non-integer amounts and unsafe magnitudes return typed failures. `pricing/rules.ts` defines markup SHAPE — `cost_plus` (sell = cost × (1+r)) versus `margin_target` (sell = cost ÷ (1−r)), never conflated — with **`MARKUP_RULES` intentionally EMPTY**: what BPT charges above cost is founder business data, and a plausible default (15%? 20%?) would invent the business's economics. `MARGIN_POLICY.minimumBasisPoints` is `null` — no floor configured is not a floor of zero. `pricing/engine.ts` runs cost → markup → net price → tax → total → margin and **refuses rather than defaults**: a missing markup rule, mixed currencies, invalid amounts and impossible margin targets each return an explicit typed failure. Margin is measured against the net price, not the tax-inclusive total — tax is collected for the government and was never the business's to keep. Every quote carries an ordered EXPLANATION whose cost/margin lines are flagged `commercial: true`. `pricing/model.ts` owns redaction in the DATA layer: `redactQuote` removes `breakdown`, `margin` and the cost side of `selling` as physically absent KEYS, not blanked values, so they cannot survive JSON into a browser payload; `toCustomerFacingQuote` delegates to that single path via the real `customer` role rather than repeating the field list. `pricing/tax.ts` is GST STRUCTURE only — place of supply, intra-state CGST+SGST versus inter-state IGST, export, and `unknown` whenever either location is incomplete — with `GST_ENABLED = false` and **`GST_RATE_BASIS_POINTS = null`**: a rate is a statutory fact about a service category, never guessed. `pricing/rate-resolver.ts` is READ-ONLY over M4, delegating to M4's own season/validation/expiry functions rather than re-implementing them, and refusing on inactive, invalid, lapsed, out-of-validity, season-ambiguous or ambiguously-matched sheets — **not one line of M4 changed**. Seam: `pricing-repository.ts` (`live:false`, and logs **nothing** — a pricing diagnostic would carry supplier costs and margins). RBAC gained a **third independent axis** in `platform/roles.ts` (additive; 64 insertions, 3 comment-only deletions): `PRICING_COST_ROLES`/`PRICING_MARGIN_ROLES` = admin + ops, and **`PRICING_APPROVAL_ROLES` deliberately EMPTY** — pricing authority sits with the founder, who is not a Payload role. The axis is not derived from `DOCUMENT_ROLE_BRIDGE`, so it widens nothing: no role is promoted to `founder`, and M4's founder-only rate amounts remain reachable only by the explicit founder actor. Surface: `/dashboard/pricing` (structural constants only — no rate, markup, margin or GST value). **NO Payload collection, NO migration, NO schema change, `payload.config.ts` untouched, `push:false` intact, zero database contact — `src/lib/pricing/` contains no `fetch`, no `process.env`, no Payload runtime import and no `console.*`.** Verified: **188/188** runtime checks; M4 **86/86**, M5 **132/132**, M6 **211/211** regressions all PASS; tsc + ESLint clean (4 pre-existing warnings, all in the committed migration file); fresh build **59/59** pages with `/dashboard/pricing` static-prerendered; independent audit PASS including a 25-check redaction probe proving no commercial key or value survives serialisation for any of the 8 roles; Preview containment verified (`/admin` fails closed) and human review passed. **M7 computes no real price** — markup rules, GST activation and quote/pricing persistence are separate founder-gated work.

**M8 defects found by post-implementation audit and FIXED before commit (2026-09-04):** Three, all latent (M8's only consumer is the founder-gated console at `live:false`, and no availability evidence source exists), all reproduced by probe before the fix and asserted by permanent checks after it.
